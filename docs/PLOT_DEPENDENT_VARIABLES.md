# Dependent-Variable Plotting Utility

The `plot-dependent-variables` utility plots dependent-variable histories saved as a Tudat CSV file.

## Overview

The command reads the dependent-variable CSV produced by `propagate-orbit` and
recreates standard plots for acceleration, ground track, Keplerian elements,
acceleration components, and animated three-dimensional trajectories.

## Synopsis

```bash
plot-dependent-variables <dep_vars_csv> [OPTIONS]
```

## Options

| Option | Description |
|--------|-------------|
| `<dep_vars_csv>` | Path to the dependent-variable CSV produced by `propagate-orbit`. |
| `--name <name>` | Satellite name used in plot labels and header filtering. Defaults to `Satellite`. |
| `-d`, `--duration <duration>` | Duration to plot, such as `1h`, `30m`, or `3600s`. If omitted, plot all data. |
| `-h`, `--help` | Show the help message and exit. |

## Input Data

The input is a saved Tudat dependent-variable CSV generated by `propagate-orbit` with the `--dep-vars` option. The `--name` value identifies the propagated satellite in labels and supported header filtering.

The first CSV header column must be:

```text
epoch_tdb_s
```

Remaining columns contain dependent-variable data with slash-separated
metadata fields written by the propagation workflow.

Validation rules:

- The CSV must not be empty.
- A header row must be present.
- The first header column must be `epoch_tdb_s`.
- Every non-empty data row must have the same number of columns as the header.
- All data values must be numeric.

## Duration Values

Durations use compact notation:

- `30s` - 30 seconds
- `5m` - 5 minutes
- `2h` - 2 hours
- `1d` - 1 day

## Examples

```bash
plot-dependent-variables dep_vars.csv
plot-dependent-variables dep_vars.csv --name ISS
plot-dependent-variables dep_vars.csv -d 6h
```

## Output

The command opens Matplotlib figures and animations for the loaded history. It
does not write new files.

The generated plots include:

1. Total acceleration norm over time.
2. Ground track.
3. Keplerian elements over time.
4. Acceleration-component norms grouped by source and type.
5. Animated three-dimensional trajectory in Earth-fixed coordinates.
6. Animated three-dimensional relative trajectory around Earth.

## Usage

**Plot dependent variables from a CSV file:**

```bash
plot-dependent-variables dep_vars.csv
```

**Use a custom satellite name for labels and header filtering:**

```bash
plot-dependent-variables --name MySat dep_vars.csv
```

**Plot only the first hour:**

```bash
plot-dependent-variables -d 1h dep_vars.csv
```

**Plot only the first 30 minutes:**

```bash
plot-dependent-variables -d 30m dep_vars.csv
```

**Generate the CSV and then plot it:**

```bash
propagate-orbit \
	-d 6h --dep-vars dep_vars.csv \
	-i "2026-05-29T00:00:00.000000 185.541742 6527.421475 -3481.030718 1.283181009 -3.414086560 -6.360538217"
plot-dependent-variables dep_vars.csv
```

**Show help:**

```bash
plot-dependent-variables --help
```

## Output Behavior

The command creates plots for the dependent-variable histories using Matplotlib. If no duration is supplied, the complete CSV history is plotted.

## Requirements

Install the optional plotting dependencies before using the command:

```bash
pip install -e '.[plotting]'
```

The input CSV must use the format produced by the propagation workflow.

The command uses NumPy, Matplotlib, and the local time utilities.
