To calibrate a numerical propagator against a historical sequence of TLEs, you must perform Batch Least-Squares Differential Correction.
Because an individual TLE contains mathematical noise and formatting truncations, fitting your high-precision numerical propagator to a time series of TLE-derived states smooths out these errors. This yields an optimal initial state vector ($\vec{r}_0, \vec{v}_0$) that matches the real physical trajectory across days or weeks.
------------------------------
## The Differential Correction Architecture
The process operates as a feedback loop. It runs a forward numerical simulation, evaluates the difference between the numerical prediction and SGP4 "observations," computes a Jacobian sensitivity matrix, and iteratively shifts the initial state vector until convergence is reached.

## Step-by-Step Algorithm Mechanics## 1. Generate the Synthetic Observation Database ($y_{obs}$)

* Collect 3 to 5 chronological TLEs spanning your time window of interest.
* Sample them uniformly (e.g., generate an "observation" point every 10 minutes) across the window.
* For every sample time $t_i$, calculate the osculating position and velocity using SGP4, and transform them into the GCRF frame as detailed previously.
* Store these as your target observations: $\mathbf{y}_{obs, i} = [\vec{r}_i, \vec{v}_i]^T$.

## 2. The Forward Numerical Run ($\hat{y}$)

* Choose your nominal starting time $t_0$ (usually the epoch of the earliest TLE).
* Set up a baseline guess for your initial 6-dimensional state vector $\mathbf{x}_0 = [\vec{r}_0, \vec{v}_0]^T$ (e.g., your first SGP4 extracted vector).
* Run your numerical propagator forward from $t_0$ to each observation time $t_i$. This generates the predicted states $\hat{\mathbf{y}}_i(\mathbf{x}_0)$.

## 3. Construct the Residual Vector ($\mathbf{b}$)
Calculate the vector difference between reality (TLE-SGP4) and your current numerical model for all time points combined:
$$\mathbf{b}_i = \mathbf{y}_{obs, i} - \hat{\mathbf{y}}_i(\mathbf{x}_0)$$ 
## 4. Compute the Sensitivity Matrix ($\mathbf{H}$)
The mapping matrix $\mathbf{H}$ defines how a tiny change in your initial conditions at $t_0$ shifts the tracking points at time $t_i$. It utilizes the State Transition Matrix (STM), $\Phi(t_i, t_0)$:
$$\mathbf{H}_i = \frac{\partial \mathbf{y}_i}{\partial \mathbf{x}_i} \Phi(t_i, t_0)$$ 

* Numerical Jacobians: If your numerical propagator does not integrate the variational equations to build the STM automatically, compute $\mathbf{H}$ using finite differencing.
* Perturb your initial condition element $x_0$ by a minor amount $\delta$ (e.g., 1 meter for position, 1 mm/s for velocity).
* Rerun the full numerical propagator for that single perturbation.
* Compute the gradient: $\frac{\Delta \text{Observation}}{\delta}$.

## 5. Solve the Normal Equations
Compute the required state correction vector $\Delta \mathbf{x}_0$ using standard weighted least-squares inversion:
$$\Delta \mathbf{x}_0 = \left( \mathbf{H}^T \mathbf{W} \mathbf{H} \right)^{-1} \mathbf{H}^T \mathbf{W} \mathbf{b}$$ 

* $\mathbf{W}$ is a diagonal weighting matrix. It normalizes the numerical scales since position magnitudes (thousands of kilometers) are much larger than velocity magnitudes (kilometers per second).

## 6. Update and Iterate
Apply the correction to your initial guess:
$$\mathbf{x}_{0, \text{new}} = \mathbf{x}_{0, \text{old}} + \Delta \mathbf{x}_0$$ 
Rerun Step 2 using this new state. Repeat the cycle until $\Delta \mathbf{x}_0$ drops below a convergence threshold (such as $10^{-6}$).

    """
    Integrates x0 (6x1 vector) from t_start to t_target using

    Returns a 6x1 state vector at t_target.
    """

    # For demonstration, we simulate a basic Keplerian step
    dt = t_target - t_start
    mu = 3.986004418e14  # m^3/s^2
    r = x0[0:3]
    v = x0[3:6]
    r_mag = np.linalg.norm(r)
    a = -mu * r / (r_mag**3)
    r_new = r + v * dt + 0.5 * a * dt**2
    v_new = v + a * dt
    return np.hstack((r_new, v_new))
